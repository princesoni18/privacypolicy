# Privacy policy: Bruno Virality Finder

Public privacy policy and data deletion instructions for the Bruno Virality Finder Meta (Instagram) developer app. The whole policy is the single file `index.html`, so it can be served from any static host.

Operator: Prince Soni, Indore, India · Contact: princezopis@gmail.com

## Get a free public URL

**Vercel (works with a private repo):**
1. Go to vercel.com/new and import `princesoni18/privacypolicy`.
2. Framework preset: **Other**. Leave build command and output directory empty. Deploy.
3. Your URL is `https://<project-name>.vercel.app/`.

**GitHub Pages (repo must be public on the free plan):**
1. Repo Settings → Pages → Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
2. Your URL is `https://princesoni18.github.io/privacypolicy/`.

## Use it in the Meta app

In the Meta developer dashboard, App settings → Basic:

- **Privacy Policy URL**: your public URL.
- **User data deletion**: choose "Data deletion instructions URL" and enter your URL with `#deletion` on the end.
